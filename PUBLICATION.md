# Source snapshot

This repository contains the Longland Schematic v0.4.2 source snapshot updated on 2026-10-06.
Build instructions and development limitations are in README.md.

Build products, installers, old release copies, caches, development-session logs,
and machine-local configuration are excluded. References to local packages or
historical validation artifacts in the original documentation do not mean those
files are included here. Build from source using the documented dependencies.

The packed runtime PNG assets and layout manifest are included so the rendered
VST interface builds from this checkout. Blender scene files, raw render passes,
Sanctus material libraries, and reference/backup scenes are not included. The
optional Blender tools require those separately held source assets. Machine-local
paths in published metadata have been replaced with relative source references.

The original working project and packaged software remain unchanged locally.
Third-party components retain their own licences. Publication does not add a new
licence grant for original project code.
